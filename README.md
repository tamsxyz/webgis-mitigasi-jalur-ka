# WebGIS Mitigasi Daerah Rawan Jalur KA

Pengabdian Masyarakat Politeknik Perkeretaapian Indonesia Madiun 2026.

Situs: https://tamsxyz.github.io/webgis-mitigasi-jalur-ka/

Peta aktif: Kerentanan Tanah Longsor pada Jalur KA, lintas Bogor-Sukabumi (km 0+000 s.d. 57+173), berdasarkan data penelitian dosen PPI Madiun tahun 2024. Peta ini disusun untuk membantu menentukan prioritas inspeksi dan pemeliharaan jalur.

Seluruh WebGIS berada dalam satu berkas index.html (Leaflet 1.9.4). Untuk memperbarui, unggah index.html versi baru dengan nama yang sama.
